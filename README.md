# World XI Cup — Escalação global

Site estático e responsivo para montar uma escalação global e jogar partidas simuladas em uma experiência inspirada em fantasy football e no estilo de times de cartas.

## Como abrir

Abra `index.html` no navegador. Não é necessária instalação.

## Recursos

- Campo tático interativo com formações 4-3-3, 4-4-2 e 3-5-2
- Elenco global com 240 atletas ilustrativos de 19 nacionalidades, busca e filtro por país
- Escalação automática, orçamento, nota média e escolha de capitão
- Copa eliminatória com oitavas, quartas, semifinal e final; derrotas encerram a campanha e empates são decididos nos pênaltis
- Adversários sorteados a cada desafio, com 18 seleções disponíveis
- Partidas rápidas com placar ao vivo, minuto a minuto e exibição somente dos gols
- Estado da escalação e campanha salvos localmente no navegador
- Layout responsivo para computador e celular

## Observação

O projeto é uma interface independente de fã. Os nomes, notas e estatísticas do elenco são ilustrativos; uma lista mundial completa e atualizada exige uma fonte de dados licenciada.
